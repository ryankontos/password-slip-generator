# More reliable scrolling and imports

- The data table, field and rule lists, and PDF preview now scroll within their own panels.
- Spreadsheet imports explain invalid sheets, row selections, and mappings before changes are applied.
- Imported field visibility is saved with the mapping, and fields are opt-in unless a saved mapping says otherwise.
- Added app icons for browser tabs, installed web apps, and the macOS Dock.
- Removed the PDF badge from the title bar and guarded background startup against another checkout using the same port.
