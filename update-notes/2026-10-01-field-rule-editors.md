# Smoother field and rule editing

- Field names, default values, rule names, conditions, and rule text now save while typing, without replacing the control being edited.
- Fixed clicks being lost when moving from an edited field to a neighbouring button.
- Rules read If … Then …, with larger controls that fit when the PDF preview is widened.
- Changing a rule action preserves custom names and compatible target fields.
- Match counts update while typing. The last condition cannot be removed accidentally.
- Field menus use native popovers with Escape dismissal and restored keyboard focus.
- Added browser checks for narrow editors, live saving, first-click actions, field menus, and unexpected JavaScript errors.
